# MCEA 클래스책임제 | Cinematic Retro Edition

## 실행
`index.html`을 브라우저에서 열면 됩니다. 이미지 파일 6개를 같은 폴더에 유지하세요.

## GitHub Pages
저장소 최상위에 `index.html`, `hero-cinematic.webp`, `chapter-1.webp`~`chapter-5.webp`를 업로드하고 Settings → Pages → Deploy from a branch → main / (root)로 설정합니다.
